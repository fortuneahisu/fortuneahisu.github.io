# Security policy

This project is a static portfolio and design showcase, but security issues should still be reported responsibly.

## Reporting a vulnerability

Please report security concerns privately through the repository maintainers or by opening a private issue channel if available.

## Scope

This policy applies to project files, generated assets, and any hosted content associated with this repository.

## Response expectations

Report details clearly and provide a minimal reproduction when possible. Valid reports will be reviewed as quickly as practical.
