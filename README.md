# Project overview

This repository hosts a personal portfolio and interactive design experiments built with plain HTML and CSS

## What is here

- A static landing page for the portfolio and personal work
- CSS-driven visual explorations and art direction experiments
- JavaScript-based UI prototypes and interface studies
- A separate HTML/CSS/JS gallery for concept series and explorations

## Run locally

Open `index.html` in a browser, or serve the project with any lightweight static server if you want live refresh and a cleaner local workflow.

## Structure

- `index.html` — main portfolio page
- `style.css` — shared styling
- `images/` — project assets
- `HTML_CSS_JS/` — experimental HTML/CSS/JS concept work

## Goals

The site is meant to showcase creative work, design thinking, and technical experiments in a clean, low-friction format.
