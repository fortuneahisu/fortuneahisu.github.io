# Code of Conduct

This project is meant to be respectful, constructive, and welcoming to everyone.

## Expectations

- Be kind and professional
- Keep feedback specific and useful
- Assume good intent
- Respect different opinions and experience levels

## Unacceptable behavior

- Harassment, threats, or personal attacks
- Disruptive, abusive, or insulting comments
- Abuse of the issue tracker or pull requests

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, or contributions that violate this standard.
